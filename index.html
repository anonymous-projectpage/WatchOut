WatchOut: Adaptive Action-Chunk Execution for Vision-Language-Action Models

Explicitly reassessing whether the currently active action chunk should be retained or replaced under updated observations.

Overview

When should the active plan be reconsidered?

Fixed-horizon execution can continue outdated actions after a disturbance, while frequent replanning can repeatedly replace a coherent plan. WatchOut treats active-plan reassessment as a separate execution-time decision.

WatchOut selectively retains or replans an active action chunk under updated observations, balancing temporal consistency and closed-loop responsiveness.
Core idea. WatchOut separates when the active plan should be reconsidered from which candidate should replace it.
Method

Active-plan reassessment + value-guided replacement

The framework combines offline actor–critic preparation with an execution-time retain-or-replan mechanism based on current action consistency.

WatchOut first prepares a value-aware VLA policy, then compares the scheduled action with immediately executable candidate actions and uses a chunk-level critic only when replacement is triggered.
1

Active-to-candidate disagreement

Compare the action scheduled by the active chunk with immediately executable actions sampled from the latest observation.

2

Candidate agreement

Use agreement across current candidates as complementary evidence that disagreement with the active action is consistently supported.

3

Value-guided replacement

If replanning is triggered, rank candidate chunks with the conservative chunk-level critic and activate the highest-valued candidate.

Retain-or-replan score

Let Cac measure active-to-candidate consistency and Ccc measure candidate-to-candidate consistency. Replanning evidence becomes stronger when current candidates agree with one another but deviate from the scheduled action.

Ct = α Ct,cc − β Ct,ac
replan if Ct exceeds the decision boundary δ
M = 16 candidatesα = β = 1δ = 0.2

Replacement selection

Action consistency decides whether to reconsider the active plan; the critic decides which candidate should replace it.

m*t = arg maxm Qϕ(ot, A(m)t)
Qϕ is a conservative chunk-level value estimate
Evaluation

Two VLA backbones, two manipulation benchmarks

WatchOut is evaluated under dynamic object-level disturbances using two action-chunk VLA backbones and two long-horizon manipulation benchmarks.

RoboTwin 2.0

Long-horizon manipulation tasks with dynamic object displacements introduced during action-chunk execution.

Backbones: π0.5, X-VLA

LIBERO-Long

Long-horizon language-conditioned manipulation tasks evaluated under the same retain-or-replan setting.

Backbones: π0.5, X-VLA
Simulation disturbances displace task-relevant objects after an action chunk has been generated, creating different levels of mismatch between the active plan and the updated scene.
Results

Selective replanning improves robustness under disturbances

Across the evaluated settings, WatchOut is compared against fixed-horizon execution, frequent replanning, temporal ensembling, bidirectional decoding, and adaptive action chunking.

Without adaptive execution, the pre-disturbance chunk continues and can fail. WatchOut detects inconsistency, replans, and recovers.

Interpretation: WatchOut preserves the current plan when it remains compatible with updated predictions and replaces it only when current candidates provide consistent evidence for reconsideration.

Real-Robot Evaluation

Physical disturbances with SO-ARM101

The real-robot protocol manually displaces a task-relevant object during chunk execution without resetting the episode, requiring online retain-or-replan decisions under real sensing and actuation.

Replan when the scene changes

When a physical displacement makes the active action incompatible with updated predictions, WatchOut triggers replanning and redirects execution toward the changed scene.

Retain when the plan remains compatible

When the scheduled action remains compatible with the latest observation, WatchOut retains the active chunk rather than continually replacing the plan.
